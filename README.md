# Real-world Data Project – Retail Sales Analysis

## Project Title
**Retail Sales Analysis and Business Insights using Python**

## Domain
Retail / E-commerce

## Objective
Analyze real-world style retail transaction data to identify sales trends, profitable categories, regional performance, payment preferences, and relationships between quantity and sales.

## Dataset
The dataset contains 500 retail transactions with:
- Order ID
- Date
- Product Category
- Region
- Quantity
- Unit Price
- Discount
- Sales
- Profit
- Payment Method

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- CSV dataset
- Jupyter Notebook / VS Code

## Analysis Performed
1. Data loading and cleaning
2. Descriptive statistics
3. Category-wise sales analysis
4. Region-wise sales analysis
5. Monthly sales trend
6. Payment-method analysis
7. Quantity vs sales relationship
8. Business conclusions

## Key Findings
- Total Sales: ₹572,636.64
- Total Profit: ₹85,598.15
- Total Orders: 500
- Total Quantity Sold: 1492
- Average Order Value: ₹1,145.27
- Best Performing Category: Electronics
- Best Performing Region: Trichy

## Conclusion
The analysis demonstrates how data science can support retail decision-making. Sales performance can be compared across categories and regions, monthly trends can guide inventory planning, and payment-method insights can support customer-service decisions.
